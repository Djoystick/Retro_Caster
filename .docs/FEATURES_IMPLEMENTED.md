# Полный список реализованных функций (На момент версии 1.2.0)

## 1. Скачивание и Парсинг
- Интеграция с `yt-dlp` (бинарник вшит в приложение).
- Парсинг ссылок Twitch с получением метаданных (Название, Длительность, Обложка стрима).
- Скачивание полных VOD'ов.
- Разделение на чанки (Chunking): Автоматическая нарезка видео через `ffmpeg` (бинарник вшит), если оно превышает лимиты (например, для Telegram).
- Механизм Auto-Delete: Очистка оригинального видео и чанков после завершения загрузки для экономии места на жестком диске.

## 2. Экспорт и Платформы
- **YouTube API:** Полная авторизация (OAuth 2.0), загрузка видео на канал, поддержка Refresh Tokens.
- **VK Video API:** Авторизация по Access Token, загрузка видео, поддержка чекбокса "Опубликовать на стене".
- **Telegram API (gram.js):** Загрузка больших файлов (до 2-4 ГБ в зависимости от Premium), отправка в конкретный канал, привязка к определенному топику (Topic ID). Поддержка потоковой загрузки чанков.

## 3. Нарезка (Fast Trimming) и Маршрутизация
- Возможность задать тайминги (Старт/Конец) индивидуально для КАЖДОЙ платформы.
- Инлайн-интерфейс в виде карточек для ввода таймингов прямо перед загрузкой.
- Мгновенная нарезка (без перекодировки видео) через `ffmpeg -c copy`.

## 4. Очередь и Автоматизация (Batch Processing)
- Глобальная очередь заданий.
- Возможность накидать множество ссылок с разными таймингами.
- Фоновый воркер, который самостоятельно обрабатывает задачи по одной, пока вы спите.
- Интеграция с системным треем: программа может сворачиваться в фон (tray), продолжать работу Очереди и выводить системные Windows-уведомления (Push).

## 5. Геймификация и UI/UX (RetroCaster Galactic Broadcast Corps)
- Полностью кастомный, бесшовный (frameless) пиксельный дизайн окна.
- Анимации на базе `framer-motion` (Пиксельное появление, эффект Typewriter для текста).
- **Система Рангов и XP:** Выдача опыта за каждую загрузку. Полоса прогресса, повышение звания от "Rookie" до элиты.
- **Звездная карта (История):** Сохранение всех выгрузок в локальную БД. Экран истории в виде Звездной карты с кликабельными ссылками на загруженные видео.
- **Dashboard (Mission Control):** Отслеживание прогресса по каждой платформе одновременно с прогресс-барами. 
- Умный Picture-in-Picture: Дашборд сворачивается в угол при навигации по приложению.
- Эффекты ЭЛТ-монитора (Сканлайны, Виньетка), геймпад-шифты (LB / RB), реагирующие на кнопки клавиатуры Q/E.

## 6. Безопасность и Стабильность
- Все API-токены надежно хранятся в зашифрованном сторадже бэкенда Electron (отвязаны от localStorage).
- Умные повторные попытки (Exponential Backoff): Если YouTube или VK отбрасывают соединение, программа автоматически ждет и повторяет загрузку (до 3 раз), не обрывая весь процесс.
- Валидация токенов перед запуском (Пре-флайт чеки), чтобы избежать ошибок спустя час скачивания.
