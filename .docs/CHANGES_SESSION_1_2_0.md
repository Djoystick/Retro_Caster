# Изменения за сессию (Версия 1.2.0)

## 1. Система очередей (Batch Processing)
- Создан глобальный стейт очереди `queue`.
- Реализован компонент `QueueView.tsx`, который показывает список загрузок в очереди.
- Написан фоновый воркер (Background Queue Worker), который автономно, по одному, берет VOD'ы из очереди, скачивает их, нарезает и отправляет на выбранные платформы.
- На левой панели добавлена кнопка "ОЧЕРЕДЬ" с бейджиком (цифрой), показывающей количество активных задач.
- Реализована функция "Picture-in-Picture": при переходе в Настройки, Историю или Очередь, окно Дашборда (со статусом загрузок) изящно сворачивается и не мешает навигации.

## 2. Инлайн Нарезка (Fast Trimming)
- Изначальная концепция "отдельного экрана нарезки" заменена на инлайн-карточки платформ прямо на экране запуска (START / Execute).
- Реализован компонент `PlatformExportCard`, который заменяет старые галочки.
- Внутри карточки теперь можно ввести время начала и конца (тайминги).
- Бэкенд переработан: `executeMasterUpload` теперь умеет мгновенно нарезать видео (stream copy через ffmpeg) во временные файлы перед загрузкой, если были указаны тайминги.

## 3. Фоновый режим и Трей
- Перехвачено событие закрытия окна (нажатие на X). 
- Добавлено нативное системное диалоговое окно (`dialog.showMessageBox`), которое спрашивает: Свернуть в трей или Закрыть программу полностью.
- При сворачивании в трей показывается красивое OS-уведомление ("RetroCaster работает в фоновом режиме").

## 4. Глубокий рефакторинг UI/UX под Ретро и Пиксель-Арт
- **Шифты LB/RB:** Декоративные кнопки LB и RB в Настройках превращены в функциональные шифты, которые переключают вкладки меню. 
- **Горячие клавиши:** Добавлены глобальные обработчики для кнопок клавиатуры `Q` (соответствует LB) и `E` (соответствует RB).
- **Рамка экрана Настроек:** Модальное окно настроек переодето в толстую двойную пиксельную рамку (оранжево-желтые скосы) с трехмерным эффектом.
- **Мигающий курсор:** Заголовок `SETTINGS` теперь имеет мигающий терминальный квадрат (`█`).
- **Scanlines:** Добавлен глобальный оверлей в виде ЭЛТ-полос (Сканлайнов) и виньетка для погружения в аркадную стилистику.
- **INSERT COIN:** Текст "INSERT COIN" внизу теперь пульсирует (animate-pulse).

## 5. Исправления багов и рефакторинг
- Поправлен синтаксис JSX при инжекте новых компонентов `PlatformExportCard`.
- Устранены ошибки несовпадения закрывающих тегов `</div>` и `</motion.div>`.
- Версия поднята до `1.2.0`.
